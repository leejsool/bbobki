# 생존 레이스 뽑기

구글 시트의 `전체 학생명단`에서 학년·반을 골라, 그 반 학생들이 폴가이즈식
장애물 레이스를 벌이고 **마지막까지 살아남은 한 명**을 뽑는 웹 게임.

교실 태블릿·전자칠판에서 열어 쓰도록 만들었다. 서버도, API 키도, 설치도 필요 없다.

---

## 어떻게 도는가

```
브라우저  ──(JSONP)──>  docs.google.com/.../gviz/tq
                         전체 학생명단 A1:X32
```

- **뽑을 때마다 시트를 새로 읽는다.** 시작 버튼을 누르는 순간 다시 요청하므로,
  직전에 시트를 고쳐도 그 내용이 바로 반영된다. 받아둔 파일을 쓰지 않는다.
- 브라우저의 `fetch` 로는 구글이 CORS 로 막기 때문에 **JSONP**(`<script>` 태그)로 읽는다.
  덕분에 중계 서버가 필요 없고, GitHub Pages 같은 정적 호스팅에 그냥 올리면 된다.
- 매 요청에 시각을 붙여 중간 캐시를 우회한다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 뼈대 (반 고르기 / 레이스 / 당첨) |
| `style.css` | 스타일 |
| `sheet.js` | 구글 시트 읽기 + A1:X32 파싱 |
| `sound.js` | 소리 (Web Audio 로 그 자리에서 합성) |
| `game.js` | 레이스 게임 (캔버스) |
| `app.js` | 화면 흐름, 폭죽 |

## 시트 쪽 준비

1. 시트 이름이 **`전체 학생명단`** 이어야 한다.
2. 공유 설정이 **"링크가 있는 모든 사용자 · 뷰어"** 여야 한다.
   (비공개면 학생 태블릿에서 못 읽는다)
3. `A1:X32` 의 모양을 지켜야 한다.
   - 1행: `1학년 1반` 처럼 학년과 반이 모두 들어간 머리글
   - 2행: 담임 이름
   - 3~32행: 번호별 학생 이름
   - 학년마다 `번호` 열 + `1반`~`7반` 열 (8열 묶음 × 3학년 = 24열 = A~X)

머리글에서 `○학년`과 `○반`을 찾아 열을 잡으므로, 반 수가 늘거나 줄어도 그대로 동작한다.

## 다른 시트를 쓰려면

`sheet.js` 맨 위만 고치면 된다.

```js
const SHEET = {
  id: '스프레드시트 URL 의 /d/ 와 /edit 사이 문자열',
  name: '전체 학생명단',
  range: 'A1:X32',
  timeout: 15000,
};
```

## 로컬에서 열어보기

`index.html` 을 브라우저로 그냥 열어도 되고, 확실하게 하려면:

```bash
python -m http.server 8765
```

그리고 <http://localhost:8765> 로 접속.

## 게임 규칙

- 장애물에 닿으면 그 자리에서 **탈락**. 부활 없음.
- **점프**로 넘을 수 있는 것: 회전바, 공, 톱니
- **점프로 못 넘는 것**: 벽, 해머, 하늘에서 떨어지는 공, 지뢰
- **대쉬**는 뒤처져 있을수록 자주 터진다. 꼴찌가 치고 나올 수 있다.
- 구간이 올라갈수록 장애물이 촘촘해지고, 오래 아무도 안 죽으면 난이도가 더 오른다.
- 장애물은 **작게, 대신 촘촘하게** 놓는다. 한 방에 여럿이 쓸려 나가지 않도록 세 가지를 넣었다.
  - 아이들은 남들이 몰린 줄을 꺼려서 위아래로 흩어져 달린다.
  - **공**은 한 명을 맞히면 터져 사라진다.
  - **회전바·해머**는 한 명을 맞히면 반대로 튕겨 나가 0.5초 동안 힘을 잃는다(흐리게 깜빡인다).
- **지뢰**: 바닥에 숨어 있어 보이지 않다가, 누가 가까이 가면 툭 튀어나와 삑삑거린다.
  **빨간 원**이 폭파 범위이고, 안쪽으로 조여드는 흰 원이 남은 시간이다. 1초쯤 뒤에 터지며,
  그 순간 빨간 원 안에 있던 아이는 탈락한다. 원 바로 밖에 있던 아이는 폭풍에 밀려나기만 한다.
  처음 드러낸 아이는 그대로 달리면 빠져나가지만, 뒤따르던 아이들은 옆으로 비켜야 한다.
- 옆에 셋 이상 붙어 있으면 가끔 한 명이 **주먹**을 휘둘러 둘레를 밀어낸다.
  탈락시키지는 않지만, 밀려나다 장애물에 부딪히는 건 별개다.
- **왼쪽 끝의 괴물 "꿀꺽이"** 가 출발 4초 뒤에 깨어난다. 앞니 왼쪽으로 처지면 그 자리에서 먹힌다.
  - **꼬리를 쫓는다.** 깨어나자마자 맨 뒤에서 달리는 아이를 따라붙고, 시간이 흐르고 사람이 줄수록,
    또 한동안 아무도 탈락하지 않을수록 더 바짝 붙는다(다 붙으면 꼬리에서 세 걸음 뒤). 누가 탈락하면 한숨 돌린다.
  - 몇 초마다 으르렁(경고 표지 ⚠️ + 화면 떨림) 하고 1초 뒤에 **확 덮친다.** 경고를 알아채는 데 걸리는 시간이
    그때그때 달라서(0.15~1초), 꼬리에서 굼뜨게 굴면 깨어 있어도 먹힌다. 한 번 덮칠 때 한 명만 문다.
  - **기절한 아이는 못 도망친다.** 기절하면 괴물이 혀를 뻗어 낚아채 입으로 끌고 간다.
    끌려오는 도중에 깨어나면 뿌리치고 살 수 있다 (무리 앞쪽에서 기절할수록 살 확률이 높다).
  - 주먹·밟기·던지기로 기절시키는 게 곧 탈락 무기가 된다.
- **점프하면 캐릭터가 커진다.** 높이 뜰수록 카메라에 가까워지는 것처럼 커져서(보통 점프 약 1.4배,
  밟고 뛰면 약 1.9배) 입체적으로 보인다. 던져진 아이도 같다.
- **마지막 한 명이 남으면 춤을 춘다.** 아래 일곱 가지 중 하나를 무작위로 골라 추고,
  당첨 화면에서도 같은 춤을 이어서 춘다.
  - **막춤**: 만세 점프 뒤에 백덤블링·옆돌기·빙글 돌기·춤·좌우로 뛰어다니기·큰 점프를 매번 섞어서
  - **문워크**: 중절모에 흰 장갑·흰 양말. 한 발은 발끝으로 버티고 다른 발은 바닥에 붙여 뒤로 밀기를 번갈아 하며
    뒤로 흘러간다. 끝에서 한 바퀴 돌고 발끝으로 서서 모자챙을 잡은 채 멈춘 뒤, 반대쪽으로 또 뒤로.
  - **삐끼삐끼**: 양손 엄지척을 번갈아 올렸다 내리며 골반을 좌우로 튕긴다. 여덟 박자 뒤에는 몸을 틀어
    한 손은 허리에, 한 손은 귀 옆에서 까딱까딱.
  - **말춤**: 선글라스. 다리를 넓게 벌리고 오-왼-오-오 / 왼-오-왼-왼 으로 발을 구른다. 앞 여덟 박자는
    손목을 겹쳐 고삐를 쥐고, 뒤 여덟 박자는 머리 위로 올가미를 돌리며 옆으로 달린다.
  - **L을 가져가**: 한 손은 이마에 L, 한 손은 배를 잡고, 메롱 하며 한 발로 콩콩 뛰면서 다리를 양옆으로 번갈아 찬다.
  - **로봇춤**: 팔을 직각으로 꺾은 자세를 뚝뚝 끊어서 바꾼다.
  - **디스코**: 한 손은 허리에, 한 손은 하늘을 찔렀다가 반대쪽 허리로. 그다음엔 두 손을 굴리며 스텝.
  춤 이름은 당첨 화면 **오른쪽 아래 구석의 거의 안 보이는 점(·)** 을 눌러야만 2.5초 동안 보인다.
  (옆 사람이 모르게 혼자 확인하는 용도)
  춤을 더하려면 `game.js` 의 `DANCES` 에 박자로 자세를 만드는 함수 하나를 추가하면 된다.
  자세는 '손과 발을 어디에 둘지'만 적으면 되고(`fl`/`fr` 발, `al`/`ar` 손, `bx`/`by` 몸통),
  팔꿈치와 무릎은 알아서 꺾인다. 발은 땅에 붙어 있고 몸통만 오르내리므로 실제 춤처럼 무게가 실린다.
- 캐릭터는 공 모양 몸통에 **두 마디로 꺾이는 팔다리**가 달려 있다. 달릴 때는 팔다리를 엇갈려 젓고,
  점프하면 두 팔을 번쩍 들고, 괴물이 코앞이면 팔을 들고 허둥지둥한다.
- 캐릭터 생김새(귀·꼬리·점박이·줄무늬·배·눈 모양·입·윙크·볼 터치, 그리고 모자·비니·머리띠·리본·안경·목도리)는
  **이름에서 정해진다.** 같은 학생은 늘 같은 모습.
- **2배속**: 레이스 화면 오른쪽 위의 `2배속` 버튼을 누르면 두 배 빠르게 진행한다. 그 기기에 기억된다.
  (한 걸음을 크게 건너뛰는 게 아니라 같은 걸음을 두 번 밟으므로 결과가 달라지지 않는다.)

## 소리

음원 파일이 없다. `sound.js` 가 Web Audio 로 그때그때 만들어 낸다.
받아올 것이 없으니 첫 소리가 늦게 나거나 끊기지 않는다.

카운트다운 / 출발 / 점프 / 착지 / 주먹 / 낙하물 / 탈락 / 구간 전환 /
셋 남았을 때 / 우승 팡파레, 열 가지.

괴물의 으르렁 / 혀 / 꿀꺽 소리, 지뢰의 삑삑(점점 빨라진다) / 폭발 소리도 같은 방식으로 만든다.

화면의 **🔊 버튼**으로 끄고 켤 수 있고, 그 기기에 기억된다.
브라우저는 사용자가 무언가를 누르기 전에는 소리를 막으므로,
'레이스 시작' 을 눌러야 소리가 깨어난다.

## 뽑기가 공정한가

게임이지만 결과는 뽑기이므로, 특정 학생이 유리해지면 안 된다. 시뮬레이션으로 확인했다.

| 항목 | 결과 |
|---|---|
| 1학년 5반(23명) 790회 | 카이제곱 **8.7** (자유도 22, 기각 임계값 33.9) → 균등 |
| 우승자의 타고난 속도 백분위 | **0.49** (공정하면 0.5) |
| 21개 학급 126회 (1920×1080) | 생존자가 1명이 아닌 경우 **0**, 우승 발표 실패 **0** |
| 한 판 길이 | 17~45초 (중앙값 31초) |

공정성을 위해 두 가지를 넣었다.

- **출발 위치를 매번 섞는다.** 번호순으로 세우면 트랙 가장자리·가운데 번호가
  유불리해져서, 실제로 우승 분포가 치우쳤다.
- **뒤처지면 빨라진다.** 안 그러면 느린 주자가 화면 밖으로 밀려나 장애물을
  아예 안 만나서 오히려 안전해졌다. (고치기 전 우승자 속도 백분위 0.30)

주먹은 누가 탈락하는지를 바꾸므로, 넣은 뒤에 같은 검사를 다시 돌려 확인했다.

괴물도 누가 탈락하는지를 바꾸므로 다시 돌렸다. (1920×1080, 23명, 400회 · 벽이 앞으로 나오는 것까지 넣은 뒤)

| 항목 | 괴물 없이 | 괴물 있음 |
|---|---|---|
| 카이제곱 (자유도 22, 기각 임계값 33.9) | 21.3 | **25.2** → 균등 |
| 우승자의 타고난 속도 백분위 | 0.50 | **0.49** |
| 한 판 길이 중앙값 | 30.0초 | 30.7초 |
| 생존자가 1명이 아닌 경우 | 0 | **0** |
| 한 판에 괴물에게 먹히는 아이 | 0 | 평균 **3.1명** (그중 99% 가 기절한 상태) |

괴물이 노리는 건 '기절한 아이'이고 기절은 누구에게나 같은 확률로 일어나므로,
특정 학생이 유리해지지 않는다. (2명·5명·31명 반, 다른 화면 크기에서도 판이 정상적으로 끝나는 것을 확인했다.)

### 긴장감을 올린 뒤 (지뢰 · 꼬리를 쫓는 괴물 · 촘촘한 장애물)

괴물이 깨어 있는 아이도 잡고 지뢰가 생겼으므로 다시 돌렸다. (1920×1080, 23명, 400회)

| 항목 | 고치기 전 | 고친 뒤 |
|---|---|---|
| 카이제곱 (자유도 22, 기각 임계값 33.9) | 19.7 | **21.5** → 균등 |
| 우승자의 타고난 속도 백분위 | 0.47 | **0.50** |
| 한 판 길이 중앙값 (10%~90%) | 28.3초 (20~35초) | **23.7초** (20~27초) |
| 생존자가 1명이 아닌 경우 | 0 | **0** |
| 한 판에 4명 이상이 한꺼번에 탈락하는 일 | 1.43번 (가장 많을 때 15명) | **0.30번** (가장 많을 때 9명) |
| 한 판에 3명 이상이 한꺼번에 탈락하는 일 | 2.37번 | **1.03번** |
| 탈락 사이의 공백 (상위 10% / 1%) | 3.4초 / 8.7초 | **2.5초 / 4.2초** |
| 한 판에 괴물에게 먹히는 아이 | 3.0명 (모두 기절한 상태) | **4.2명** (기절 3.0 + 깨어 있다가 1.2) |
| 한 판에 지뢰로 탈락하는 아이 | - | **1.5명** |

뒤처지면 괴물에게 잡히게 되었으므로, 타고난 발 빠르기는 거의 같게(±1%) 하고 앞뒤 순서는
몇 초마다 바뀌는 '컨디션'이 가르게 했다. 그래서 늘 꼴찌인 아이가 생기지 않는다.

2명·3명·5명·31명 반과 다른 화면 크기(1280×720, 1024×768, 세로로 세운 820×1180)에서도 모든 판이
한 명만 남기고 정상적으로 끝났다. 인원이 적은 반은 금방 끝난다(2명 중앙값 8초, 5명 13초, 31명 26초).
